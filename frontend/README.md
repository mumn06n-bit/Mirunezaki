# 狐崎みる

## 概要

狐崎浜周辺の海洋情報をわかりやすく確認できることを目的として開発したWebサイトです。
気温・水温・塩分濃度・溶存酸素の情報を確認・比較する機能を提供します。

## 主な機能

- 海洋情報の取得・確認
- 日時ごとのデータ管理
- データのグラフ・散布図表示

## 必要なパッケージ

- react-router-dom
- lucide-react
- -D vite-tsconfig-paths
- react-calendar
- echarts echarts-for-react
- tslib
- leaflet react-leaflet
- D @types/leaflet
- --save-dev @types/node

## パッケージ導入方法

ターミナルで “npm.cmd 各パッケージ名”

## 使用技術

フロントエンド：React、TypeScript

## ディレクトリ構成


### frontendフォルダ内の詳細は以下

# ＜DataPage＞

### 概要

気温、水温、塩分濃度、溶存酸素の4つの項目について、選択した日付と時刻のセンサデータを表示する画面です。溶存酸素は、設定画面で選択したDOセンサ（DO01〜DO03）の値を表示します。

### 操作

- **日付の選択（カレンダーアイコン）**：日付選択画面に移動し、表示する日付を変更できます。
- **時刻の選択（プルダウン）**：00:00から23:30まで、30分刻みで時刻を選択できます。
- **更新ボタン**：現在の日付と、現在時刻を30分単位で切り捨てた時刻に戻します。
- **センサデータの表示**：選択した日付と時刻に対応する気温、水温、塩分濃度、溶存酸素を表示します。

### データの取得と表示

- **データ取得**：統合API（`/api/sensors`）から選択した日付のセンサデータを取得します。
- **時刻の照合**：取得したデータの日時と選択中の時刻を照合し、一致するデータを表示します。
- **DOセンサの切り替え**：設定画面で保存したセンサIDに応じて、`oxygen1`、`oxygen2`、`oxygen3`のいずれかを表示します。
- **データが見つからない場合**：該当するデータがない場合は、24時間以内の場合は直近のデータを、24時間以上経過した場合は数値の代わりに空欄が表示されます。その際に古いデータであることや24時間以上データがないというメッセージを表示します。単位のみが表示されます。
- **データ取得エラー**：取得に失敗した場合は、コンソールにエラーを出力し、データを表示しない状態にします。

### コードの構成

- `DataPage.tsx`：日付・時刻の管理、APIからのデータ取得、センサデータの表示、カレンダー画面への遷移を処理します。
- `DataPage.css`：日付表示エリア、時刻選択欄、センサデータ一覧、カレンダーアイコン、更新ボタンの見た目を設定します。
- `sensorData.ts` の `fetchSensorData`：選択した日付のセンサデータを取得します。
- `PageLayout`：ページの共通レイアウトとタイトルを設定します。

# ＜Calendar＞

### 概要

カレンダーからセンサデータを表示する日付を選択する画面です。選択した日付をデータ画面に渡し、指定した日のセンサデータを確認できます。未来の日付は選択できません。

### 操作

- **日付の選択**：カレンダーの日付をクリックまたはタップして選択します。
- **月の切り替え**：カレンダー上部の矢印から表示する月を切り替えます。
- **年の切り替え**：カレンダー上部の二重矢印から表示する年を切り替えます。
- **OKボタン**：選択した日付をデータ画面に渡して戻ります。
- **戻るボタン**：選択した日付をデータ画面に渡さず戻ります。

### カレンダーの見た目と動き

- **初期表示の日付**：データ画面から渡された日付がある場合は、その日付を初期選択状態にします。渡されていない場合は、現在の日付を選択します。
- **未来の日付の制限**：`maxDate={new Date()}`により、今日より未来の日付は選択できません。
- **日付の表示**：各日付には日付の数字のみを表示し、曜日や月の情報はカレンダーの見出しで確認できます。
- **選択中の日付**：青色の枠線で囲み、文字色と太さを変更して強調します。
- **現在の日付**：背景が黄色になる。
- **曜日の色分け**：日曜日は赤色、土曜日は青色、月曜日から金曜日は黒色で表示します。
- **月の切り替え部分**：背景を設定し、年月と矢印が見やすいデザインにしています。

### コードの構成

- `Calendar.tsx`：カレンダーの表示、選択日付の管理、データ画面への日付の受け渡しを処理します。
- `Calendar.css`：カレンダーの背景、選択日の枠線、曜日の色、月切り替え部分、OKボタンのデザインを設定します。
- `react-calendar`：カレンダーの表示と日付選択の機能を提供します。
- `PageLayout`：ページタイトル「日付選択」と戻るボタンを表示します。

# <GraphPage>
### **概要**

気温、水温、塩分濃度、溶存酸素の4つの項目の推移を折れ線グラフで表示する画面です。項目と表示期間（日・月・年）を切り替えられ、設定画面で決めた適正値が緑の線で表示されます。グラフを横にスクロールすると、過去のデータも見られます。

### 操作

- **項目の選択（プルダウン）**：気温・水温・塩分濃度・溶存酸素から選びます。初期値は「水温」です。
    - 溶存酸素は、設定画面で選んだ DO センサ（DO01〜03）の値を表示します。
- **表示期間の切り替え（日／月／年）**：初期値は「月」です。

| モード | 1点の単位 | 表示範囲 |
| --- | --- | --- |
| 日 | 30分ごとの値（48点） | 今日だけ（日付は選べません） |
| 月 | 1日ごとの平均 | データがある最初の日から最新の日まで |
| 年 | 1か月ごとの平均 | データがある最初の月から最新の月まで |

### グラフの見た目と動き

- **目標値の線（緑）**：設定画面で保存した適正値を横線で表示します。水温は20、塩分は30、溶存酸素は3.5が初期値です。気温には適正値の線がありません。
- **横スクロール**：1画面に表示する点の数が決まっていて、左にドラッグすると過去のデータを見られます。
    - PC：日モード24点、月モード31点、年モード12点
    - スマホ：日モード6点、月モード7点、年モード12点
    - 最初は最新のデータが見える位置で開きます。
- **横軸のラベル**：月・年モードでは2段で表示します（上段に「◯月」や「◯年」、下段に日や月）。スクロールしても、左端に月や年が必ず表示されます。
- 点をタップすると、値が表示されます。
- データ取得中はスピナー、取得に失敗したときはエラーメッセージを表示します。
- 日モード時その日のデータが一つもない場合、”データがありません”を表示します。

### コードの構成

- GraphPage.tsx：メニュー（項目と期間の切り替え）、単位と適正値の決定
- GraphPage.css：グラフ画面の見た目（メニュー背景、項目選択ボタン、グラフ表示エリアのスクロール）
- GraphChart.tsx：データ取得と ECharts の描画（スクロールと横軸ラベルの処理を含む）
- GraphChart.tsx ：グラフ画面でのグラフ表示領域の定義
- sensorData.ts の `makeGraphPoints`：生データを、30分ごと／日ごと／月ごとの平均に集計

# <ComparePage>
## 概要

センサデータを複数の期間で比較する画面。気温・水温・塩分濃度・溶存酸素から比較対象を選択し、日・月・年単位でデータを比較できる。

また、相関モードを有効にすると、2種類のセンサの値の関係を散布図で確認できる。

## 主な機能

### 1. 比較条件の設定

`CompareSetting.tsx` で、比較するデータの種類や期間を設定する。

- センサの種類を選択する。
    - 気温
    - 水温
    - 塩分濃度
    - 溶存酸素
- グラフ期間を選択する。
    - 日
    - 月
    - 年
- 比較する期間を追加・削除する。
- 期間ごとに異なる色を設定する。
- 比較期間は最大5つまで設定できる。
- 溶存酸素の通常比較では、DO1・DO2・DO3を選択できる。
- 相関モードでは、比較するセンサを2種類選択する。

### 2. 設定の保存

比較設定は `localStorage` の `compareSettings` にJSON形式で保存する。

保存する主な情報は以下のとおり。

- 相関モードの有効・無効
- センサの種類
- 相関モードで選択したセンサ
- グラフ期間
- 比較対象の期間と色

設定保存時には、相関モードでセンサが2種類選択されているか、比較期間が設定されているか、期間が重複していないかを確認する。

保存が完了すると、比較画面（`/compare`）へ移動する。

### 3. 比較結果の表示

`ComparePage.tsx` では、保存された設定を読み込み、選択内容と比較対象の期間を画面に表示する。

- 選択したセンサの種類を表示する。
- 比較対象の期間を色付きのタグで表示する。
- 溶存酸素の通常比較では、期間とDOセンサ名を表示する。
- 相関モードがOFFの場合は `CompareChart.tsx` を表示する。
- 相関モードがONの場合は `CompareScatter.tsx` を表示する。
- 設定ボタンから比較設定画面へ戻ることができる。

### 4. 期間別比較グラフ（CompareChart.tsx）

EChartsを使用して、同じセンサの値を複数の期間で比較する折れ線グラフを表示する。

- API（`/api/sensors?date=...`）から期間ごとのセンサデータを取得する。
- 期間ごとに色分けした折れ線グラフを表示する。
- データが欠損している場合は `null` として扱う。
- センサの種類に応じて、気温・水温・塩分濃度・溶存酸素の値を使用する。
- 溶存酸素では、比較期間ごとに選択されたDOセンサを使用する。
- 日・月・年の表示モードに応じてデータを集計・表示する。
- グラフの縦軸は選んだ種類により変更する。（溶存酸素は2.0~8.0,塩分濃度は25~35）

#### 表示モード

| モード | 横軸 | データの扱い |
| --- | --- | --- |
| 日 | 時間 | 00:00～23:30の30分単位で表示 |
| 月 | 日 | 日ごとの平均値を表示 |
| 年 | 月 | 月ごとの平均値を表示 |

### 5. 相関図（CompareScatter.tsx）

相関モードでは、選択した2種類のセンサの値をX軸とY軸に設定し、散布図を表示する。

- APIから比較対象期間ごとのデータを取得する。
- X軸・Y軸にセンサの種類と単位を表示する。
- 期間ごとに異なる色でデータ点を表示する。
- 日モードでは取得したデータをそのまま使用する。
- 月モードでは日ごとの平均値を使用する。
- 年モードでは月ごとの平均値を使用する。
- X軸またはY軸の値が `null` のデータ点は表示しない。

## 処理の流れ

1. ユーザーが比較設定画面でセンサの種類、表示期間、比較対象の期間を選択する。
2. 必要に応じて相関モードと相関対象のセンサを設定する。
3. 設定を `localStorage` に保存する。
4. 比較画面が保存済み設定を読み込む。
5. 設定に応じて `CompareChart.tsx` または `CompareScatter.tsx` を表示する。
6. 各コンポーネントがAPIからセンサデータを取得する。
7. 取得データを表示モードに応じて加工し、EChartsでグラフを描画する。

## コードの構成

- `ComparePage.tsx`：比較結果画面の表示、選択したセンサや比較期間の表示、通常比較と相関比較の切り替え
- `ComparePage.css`：比較画面の見た目
- `CompareSetting.tsx`：比較条件の設定（センサの種類、比較期間、相関モードの切り替え）、入力チェック、設定の保存
- `CompareSetting.css`：比較設定画面のスタイル
- `CompareChart.tsx`：センサ1種類の期間別比較グラフ
- `CompareChart.css`：比較グラフのスタイル
- `CompareScatter.tsx`：センサデータの取得と ECharts による散布図の描画。相関を調べる2種類のセンサのデータを取得し、比較期間ごとに表示
- `CompareScatter.css`：相関図のスタイル
- `compareData.ts`：比較設定の型定義やセンサの単位取得


# ＜SettingPage＞

### 概要

DOセンサの選択と、水温・塩分濃度・溶存酸素の適正値を設定する画面です。
設定した値はブラウザの`localStorage`に保存され、再び画面を開いたときにも読み込まれます。

### 操作

- **DOセンサの選択**：プルダウンからDO01、DO02、DO03のいずれかを選択します。
- **地図選択ボタン**：地図画面に移動してDOセンサを選択できます。地図画面で選択したセンサは設定画面に反映されます。
- **水温の適正値**：10.0〜30.0℃の範囲から、0.5℃刻みで選択します。
- **塩分濃度の適正値**：25〜35‰の範囲から、1‰刻みで選択します。
- **溶存酸素の適正値**：3.5〜7.5mg/Lの範囲から、0.2mg/L刻みで選択します。
- **保存ボタン**：選択したDOセンサと3項目の適正値を保存します。保存が完了すると「設定を保存しました」というメッセージが表示されます。

### 設定の保存と読み込み

- **初期値**：DOセンサはDO01、水温は20.0℃、塩分濃度は30‰、溶存酸素は6mg/Lです。
- **保存先**：`localStorage`に、`doSensor`、`temperature`、`salinity`、`oxygen`というキーで値を保存します。
- **設定の復元**：画面を開いたときに保存済みの値を読み込み、各プルダウンに反映します。
- **地図からの選択結果**：地図画面からセンサIDを受け取った場合、そのIDを選択状態にし、`doSensor`にも保存します。

### コードの構成

- `SettingPage.tsx`：設定値の管理、`localStorage`からの読み込み、設定の保存、地図画面への遷移を処理します。
- `SettingPage.css`：背景色、設定項目の配置、プルダウン、区切り線、保存ボタン、地図選択ボタンのデザインを設定します。
- `PageLayout`：ページタイトル「設定」を含む共通レイアウトを提供します。

# ＜map＞

### 概要

DOセンサ（DO01〜DO03）と塩分センサの設置位置を地図上に表示する画面です。DOセンサを選択し、設定画面に選択したセンサを渡すことができます。また、各センサの最新の緯度・経度と位置情報の取得日時を表示します。

### 操作

- **センサの選択**：地図上のDO01〜DO03のマーカーをクリックまたはタップして選択します。
- **選択中のセンサ表示**：現在選択しているDOセンサのIDを地図の下に表示します。
- **OKボタン**：選択したDOセンサのIDを設定画面に渡して移動します。
- **塩分センサ**：地図上に表示しますが、選択することはできません。
- **位置情報の確認**：地図の下にある一覧から、各センサの緯度・経度と位置情報の取得日時を確認できます。

### 地図の見た目と動き

- **DOセンサのマーカー**：白色の背景に青色の枠線で表示します。選択中のマーカーは青色の背景と白色の文字に変わり、少し拡大されます。
- **地図の移動・拡大操作の制限**：マウスホイール、ダブルクリック、タッチによるズームを無効にしています。また、表示範囲を指定した範囲内に制限しています。
- **マーカーの座標**：地図上のマーカーには、コード内に定義した固定座標を使用します。APIから取得した最新の位置情報は、地図上のマーカーを動かすためではなく、画面下部の一覧表示に使用します。
- **位置情報の取得中**：緯度・経度の欄に「取得中...」と表示します。
- **位置情報が取得できない場合**：緯度・経度の欄に「取得できません」と表示します。
- **取得日時の表示**：位置情報の取得日時を表示します。日時が取得できない場合は「取得できません」と表示します。

### コードの構成

- `map.tsx`：地図の表示、センサマーカーの生成、DOセンサの選択、位置情報の取得、設定画面への遷移を処理します。
- `map.css`：地図のサイズ、センサマーカーの色と形、選択中のマーカー、OKボタン、位置情報一覧のデザインを設定します。
- `sensorData.ts` の `fetchLatestSensorPositions`：センサの最新位置情報を取得します。
- `PageLayout`：ページタイトル「地図」と戻るボタンを含む共通レイアウトを提供します。
